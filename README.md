# Reuse Tab

既に開いている URL を新しいタブで開こうとしたとき、既存のタブで開き直す Chrome 拡張機能（Manifest V3）。

## 動作

- **同一判定**: `origin + pathname` で判定。query・hash・末尾スラッシュの違いは無視する。対象は http/https のみ。シークレットと通常ウィンドウは別扱い。
- **新規タブ**: 新しく作られたタブが最初に http(s) へ遷移するとき、同じキーの既存タブがあれば
  1. 既存タブを新しい URL で上書き（完全一致なら再読み込み）
  2. 既存タブとそのウィンドウをアクティブにする
  3. 新規タブを閉じる
- **統合**: ツールバーアイコンのクリックで、キーごとに1タブだけ残して他を閉じる。バッジに重複数を表示。
- **優先順位**（残すタブ・開き直す先）: ピン留め > アクティブ > 最後に使ったタブ
- 起動直後 10 秒間に作られたタブ（セッション復元）は対象外。

## インストール

1. `chrome://extensions` でデベロッパーモードを有効にする
2. 「パッケージ化されていない拡張機能を読み込む」でこのディレクトリを選ぶ
